# Mukesh Babu — Technology & Open-Source Portfolio

Personal portfolio website for an ISC student exploring AI, technology, website management and open-source projects.

**Live portfolio:** https://mmukeshbabu2010-dot.github.io/mukesh-portfolio/
**LinkedIn:** https://linkedin.com/in/mmukesh-babu

## Separate pages

- `index.html` — Home
- `experience.html` — Independent initiatives
- `projects.html` — Selected projects
- `education.html` — Education
- `about.html` — About and areas of interest
- `contact.html` — Contact details and profile links

## Shared assets

- `assets/css/style.css` — Shared visual design and responsive styles
- `assets/js/main.js` — Shared reveal and cursor effects, with reduced-motion support
- `favicon.svg` — Site icon
- `images/` — Project imagery

## Run locally

Open `index.html` in a browser. This is a static website and does not require a build step. Keep the `assets/`, `images/`, and existing policy pages alongside the HTML files.
