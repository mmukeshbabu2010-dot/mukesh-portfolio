## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser.
3. Keep the existing assets and image folders alongside the HTML file.

This is a static website; no build step is required to preview the page.

## Updating the portfolio

- Edit the content in `index.html`.
- Keep project descriptions and links accurate to their current repository state.
- Preserve the existing visual system, responsive styles and accessibility behaviour.
